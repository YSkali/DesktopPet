## 1. 环境准备

### 1.1 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11（色键透明仅 Windows 支持） |
| Python | 3.9 或更高版本 |
| 依赖 | Pillow >= 10.0.0 |
| 可选 | psutil >= 5.9.0（更精确的 CPU/内存/电池感知） |

### 1.2 验证 Python 环境

```bat
python --version
python -c "import tkinter; print('tkinter OK', tkinter.TkVersion)"
```

**预期输出**：
```
Python 3.14.3
tkinter OK 8.6
```

> 如果提示 tkinter 找不到，说明 Python 是不带 Tk 的精简版，
> 请从 [python.org](https://www.python.org/downloads/) 重新安装并勾选 "tcl/tk"。

## 2. 安装依赖

### 2.1 创建虚拟环境（推荐）

```bat
python -m venv .venv
.venv\Scripts\activate
```

### 2.2 安装依赖

```bat
pip install -r requirements.txt
```

**开发/测试/打包额外依赖**：

```bat
pip install -r requirements-dev.txt
```

**可选：安装 psutil 获得更精确的系统感知**：

```bat
pip install ".[awareness]"
```

### 2.3 验证安装

```bat
python -c "import PIL; print('Pillow', PIL.__version__)"
```

## 3. 运行方式

### 3.1 一键启动（最简单）⭐

双击 `start.bat`，脚本会自动检查 Python、安装缺失依赖并启动。

### 3.2 命令行启动

```bat
python run.py
```

### 3.3 作为模块运行

```bat
python -m desktoppet
```

### 3.4 手动分步（需要精细控制时）

```bat
python scripts/prepare_assets.py   # 处理素材（生成 assets_processed/）
python run.py                      # 启动
```

## 4. 功能检验清单

启动桌宠后，按以下步骤逐项验收：

### 4.1 基础功能

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 启动 `python run.py` | 桌面出现透明背景小宠物，无标题栏，始终置顶 |
| 2 | 观察宠物移动 | 自动左右走动，偶尔停下休息 |
| 3 | 走到屏幕边缘 | 自动掉头，不会跑出屏幕 |
| 4 | 左键点击宠物 | 播放点击反应动画，约 0.8 秒后恢复待机 |
| 5 | 左键按住拖动 | 宠物跟随鼠标移动，松手后回到待机 |
| 6 | 右键点击宠物 | 弹出菜单（设置面板 / 切换角色 / 打招呼 / 系统状态 / 关于 / 退出） |
| 7 | 菜单点「关于桌宠」 | 弹出信息框（版本号 + 操作说明 + 亲密度） |
| 8 | 菜单点「退出」 | 程序正常退出 |

### 4.2 交互功能

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 左键单击宠物 | 头顶气泡随机弹出**一句台词**（如"呀！""别戳我啦～"），并**原地上下一跳** |
| 2 | 左键双击宠物 | 触发**抚摸反应**（台词如"好舒服～"） |
| 3 | 按住拖动后松手 | 松手时气泡弹出**拖拽台词**（如"要带我去哪呀？"），随后回到待机 |
| 4 | 让宠物待机约 25 秒 | 宠物**自发说一句话**（自言自语） |
| 5 | 连续多次单击/双击 | 每次台词不同（随机），反复点击不会卡住 |
| 6 | 右键 → 关于桌宠 | 弹窗显示版本、当前心情、**亲密度：N 次互动** |

### 4.3 系统感知功能

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 启动时观察控制台 | 打印当前心情（如"早上好呀！"） |
| 2 | 打开任务管理器制造 CPU 负载 | 宠物动作变慢、休息增多（心情变为"好累呀"） |
| 3 | 右键 → 系统状态 | 弹窗显示时段 / CPU / 内存 / 电池 / 心情 |

### 4.4 角色包切换

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 右键 → 切换角色 | 显示 7 个内置角色（小熊/小鹿/小狼/小狐狸/小野猪/小兔子/小马） |
| 2 | 点击某个角色 | 宠物立即切换为对应角色 |
| 3 | 重启桌宠 | 保持切换后的角色 |

### 4.5 设置面板

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 右键 → 设置面板… | 打开控制台窗口，左侧导航显示 9 个页面 |
| 2 | 逐页点击 | 每页正常渲染，无报错 |
| 3 | 修改宠物大小 | 即时生效，宠物尺寸变化 |
| 4 | 修改不透明度 | 即时生效，透明度变化 |
| 5 | 点「保存并应用」 | 状态栏显示"✓ 已保存并应用"，config.json 更新 |
| 6 | 按 Ctrl+S | 同「保存并应用」 |
| 7 | 按 Esc | 关闭控制台 |

### 4.6 配置文件

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 复制 `config.example.json` 为 `config.json` | — |
| 2 | 修改 `move_speed` 为 8 | 重启后宠物移动明显变快 |
| 3 | 修改 `talk_on_click` 为 false | 点击/拖拽不再说话 |

## 6. 常见问题排查

| 现象 | 原因 / 解决 |
|------|-------------|
| `ModuleNotFoundError: No module named 'desktoppet'` | 不在项目根目录运行；请在根目录用 `python run.py` |
| 宠物是纯色方块、无角色 | `assets_processed\` 为空或素材未处理，重跑 `python scripts/prepare_assets.py` |
| 报 `OSError: [Errno 5] Input/output error` | 若是网络盘/同步盘写入 `.pyc` 失败所致；把项目放到本地磁盘再试 |
| 点击没反应 | 点在**透明区域**不算；请点在角色图像上 |
| 打包后右键「关于」没反应 | 确认用的是新版 `desktoppet/pet.py`（已改用弹窗） |
| `build` 目录没生成 exe | 看 `packaging/build.bat` 输出，通常是缺 `cx_Freeze`：`pip install cx_Freeze` |
| 无法激活 venv（PowerShell 报执行策略） | 运行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，或改用 CMD |
| 控制台页面加载失败 | 查看 `logs/desktoppet.log` 中的错误信息 |
| 角色包不显示 | 确认 `pets/<name>/` 下有 `idle/` 等状态子目录且包含 PNG 文件 |

## 7. 开发流程

### 7.1 开发环境搭建

```bat
pip install -r requirements.txt -r requirements-dev.txt
```

### 7.2 运行测试

```bat
pytest -q                          # 全部测试
pytest tests/test_pet.py -q        # 单个测试文件
pytest tests/test_awareness.py -q  # 单个测试文件
```

### 7.3 代码检查

```bat
python scripts/check.py             # 完整自检
```

### 7.4 新增控制台页面

1. 在 `desktoppet/ui/pages/` 新建模块
2. 继承 `ConfigPage` 并用 `@register` 注册
3. 在 `pages/__init__.py` 中 import

```python
# desktoppet/ui/pages/myfeature.py
from ..registry import register
from ..widgets import ConfigPage

@register
class MyFeaturePage(ConfigPage):
    id = "myfeature"
    title = "我的功能"
    order = 60
    fields = (
        {"key": "move_speed", "label": "移动速度", "kind": "int", "from": 1, "to": 10},
    )
```

### 7.5 新增角色包

**方式一：脚本一键生成**

```bat
python scripts/build_pet.py upload/my_pet --display-name "咪咪" --author yourname
```

**方式二：手动放置**

把处理好的 PNG 放进 `pets/<name>/<state>/`，再补一个 `manifest.json`。

## 8. 打包发布

### 8.1 打包为 exe

```bat
python scripts/prepare_assets.py
python packaging/setup_cx.py build
```

或双击 `packaging/build.bat`。

### 8.2 验证打包产物

1. 进入 `build/exe.*/` 目录
2. 双击 `DesktopPet.exe`
3. 确认：
   - 宠物正常显示、走动（无控制台窗口是正确的）
   - 右键 → 关于桌宠，弹窗正常
   - 把整个文件夹拷到别的目录/U 盘再运行，确认能独立运行

### 8.3 发布

1. 更新 `desktoppet/version.py` 中的 `__version__`
2. 更新 `CHANGELOG.md`
3. 提交代码并推送
4. 在 GitHub 创建 Release，上传 `build/exe.*/` 目录的压缩包
